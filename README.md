# astroFETCH

## A website that fetches NASA's data to show you the APOD, the Astronomy Picture of the Day!


astroFETCH uses the NASA's API in order to grab data and to show you the picture of the day, as well as letting you choose to select any day to look at, not just the current day!

You can access it at: https://awesomesauce4646.github.io/astro-fetch/

### AI USAGE:

Used AI to debug why the date system wasn't working.
